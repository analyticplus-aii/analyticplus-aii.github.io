Политика конфиденциальности

Приложение: Jarvis Analytic Plus · Обновлено: 8 сентября 2026 г.

Настоящая политика описывает, какие данные обрабатывает приложение Jarvis Analytic Plus (далее — «Приложение») при подключении к сервисам Google, и как эти данные используются.

Приложение предназначено исключительно для личного использования владельцем аккаунта. Оно не распространяется публично, не имеет сторонних пользователей и не собирает данные третьих лиц.

1. Какие данные запрашиваются

После вашего явного согласия в окне авторизации Google приложение получает доступ к:

2. Как используются данные

Данные обрабатываются только для выполнения задач, которые вы поручаете Приложению напрямую. Приложение не сканирует почту и файлы в фоновом режиме без вашего запроса.

Приложение не продаёт, не передаёт и не публикует ваши данные, не использует их для рекламы и не применяет для обучения моделей.

3. Обработка языковой моделью

Приложение работает на основе больших языковых моделей. Это означает, что содержимое, необходимое для выполнения вашего запроса (например, текст письма, который нужно проанализировать), передаётся провайдеру модели по защищённому соединению для обработки в момент выполнения запроса.

Передаётся только та информация, которая нужна для конкретной задачи. Провайдеры моделей обрабатывают запросы согласно собственным политикам конфиденциальности.

4. Хранение данных

  • Токен доступа Google хранится на частном сервере владельца в зашифрованном канале и не передаётся третьим лицам.
  • Содержимое писем, документов и таблиц не копируется в отдельную базу — оно запрашивается у Google в момент выполнения задачи.
  • История диалогов хранится локально на сервере владельца для поддержания контекста разговора.

5. Как отозвать доступ

Вы можете в любой момент отозвать доступ Приложения к вашему аккаунту Google:

  • Откройте myaccount.google.com/permissions
  • Найдите в списке «Jarvis Analytic Plus»
  • Нажмите «Закрыть доступ»

После отзыва Приложение немедленно теряет возможность обращаться к вашим данным.

6. Безопасность

Соединения с Google выполняются по HTTPS. Доступ к серверу, на котором работает Приложение, ограничен владельцем. Приложение запрашивает минимально необходимый набор разрешений для заявленных функций.

7. Изменения политики

При изменении состава обрабатываемых данных эта страница будет обновлена с указанием новой даты в заголовке.
